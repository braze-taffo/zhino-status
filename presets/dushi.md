# 都市 · 人物状态栏

把下面「更新规则」整段贴进世界书（常驻，或关键词：都市、职场、好感度）。
条目备注或关键词写上 `zns:dushi` 或 `世界观:都市`。

开局变量见 `dushi.initvar.yaml`，世界书条目标题或备注包含 `[initvar]`，正文粘贴该文件。

字段名：职业、金钱、体力、精力、心情、好感度、人际关系、身份、位置、状态。多角色放在 `角色` 下。

## 更新规则（粘贴用）

```
【人物状态 · 都市】
维护每个出场角色的生活状态。有 MVU 时写补丁；没有则在回复最末尾给完整 <status> 快照。

数值约定：
- 体力、精力、好感度范围 0–100。过劳、熬夜、受伤让体力和精力下降；休息回升。低于 25 视为强撑。

- 人际关系是列表，每条建议写成「人名 · 关系 / 近况」。
- 好感度若是 [数值, "说明"]，只改第一个元素。
- 只改这次情节动到的角色。路人不必建档；重要配角第一次登场时补一条 replace / add。
```
