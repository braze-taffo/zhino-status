# 末日 · 人物状态栏

把下面「更新规则」整段贴进世界书（常驻，或关键词：末日、丧尸、据点、感染）。
条目备注或关键词写上 `zns:moshi` 或 `世界观:末日`。

开局变量见 `moshi.initvar.yaml`（条目标题或备注含 `[initvar]`）。

字段名：生命、饥饿、口渴、感染度、理智、弹药、物资、据点、武器、状态。多角色放在 `角色` 下。

## 更新规则（粘贴用）

```
【人物状态 · 末日】
生存数值要跟着情节走。有 MVU 时写补丁；没有则在回复最末尾给完整 <status> 快照。

数值约定（默认 0–100）：
- 生命：受伤下降，包扎、休息缓慢回升。0 为濒死或死亡，不要无声复活。
- 饥饿、口渴、感染度：越高越糟。进食、喝水降低饥饿和口渴；感染上升后很难自行回落。
- 理智：目睹死亡、长期失眠、孤立会下降；安全的据点和同伴能稳住它。
- 弹药是整数（发）。开枪要扣。物资是列表，消耗就从列表删掉或改数量。
- 据点、武器用短句。状态用短标签，如 擦伤、缺觉、发热。
- 只更新在场角色。分头行动时两个角色可以同时改。

<UpdateVariable>
<Analysis>谁受伤、谁消耗了食物或子弹、感染有没有变。</Analysis>

</JSONPatch>
</UpdateVariable>
```
