# 西幻 · 人物状态栏

把下面「更新规则」整段贴进世界书（常驻，或关键词：西幻、冒险者、公会、魔法）。
条目备注或关键词写上 `zns:xihuan` 或 `世界观:西幻`。

开局变量见 `xihuan.initvar.yaml`（条目标题或备注含 `[initvar]`）。

字段名：种族、职业、等级、HP、MP、金币、阵营、装备、技能、状态。多角色放在 `角色` 下。
HP / MP 可以写 `当前/上限`（如 28/120），或拆成 HP 与 HP上限、MP 与 MP上限。

## 更新规则（粘贴用）

```
【人物状态 · 西幻】
维护冒险者状态。有 MVU 时写补丁；没有则在回复最末尾给完整 <status> 快照。

数值约定：
- HP、MP 用「当前/上限」。受伤、施法、喝药、休息都要改当前值，不要只写叙事。
- 等级、金币是整数。升级时同时提高 HP上限 / MP上限。
- 装备、技能是列表。换装时去掉旧的、加上新的。状态用短标签：轻伤、祝福、中毒、专注。
- 种族、职业、阵营不轻易改；转职、叛教、诅咒改变种族时要改。
- 只更新在场角色。

<UpdateVariable>
```
