# 修仙 · 人物状态栏

把下面「更新规则」整段贴进世界书（常驻，或关键词：修仙、境界、灵力、功法）。
条目备注或关键词写上 `zns:xiuxian` 或 `世界观:修仙`，状态栏会据此选中修仙预设。

初始数值用同目录的 `xiuxian.initvar.yaml`：世界书条目的标题或备注必须包含 `[initvar]`，正文粘贴该文件。这是 MVU（MagVarUpdate / 酒馆助手变量框架）的开局变量，会进最新楼的 `stat_data`。

字段名要和状态栏预设一致：境界、灵根、修为、灵力、寿元、心境、功法、法宝、灵石、状态。多角色放在 `角色` 下面，键名就是角色名。

## 更新规则（粘贴用）

```
【人物状态 · 修仙】
你必须维护角色状态。有 MVU 时用补丁；没有 MVU 时，在回复最末尾另给一份完整快照。

数值约定：
- 修为、灵力、寿元若写成「当前/上限」（如 82/120）或对象 {"当前":82,"上限":120}，上限以你写的为准。
- 也可以分成两个字段：修为 与 修为上限，灵力 与 灵力上限，寿元 与 寿元上限。
- 若变量叶子是 [数值, "说明"]，只改第一个元素，说明留着。
- 功法、法宝、状态是列表。新增用 add 到路径末尾 /- ；失去则 remove。
- 灵石是整数。境界、灵根、心境是短句，不要写成长文。
- 只改这次情节真正动到的项。境界突破、受伤、施法、交易、寿元流逝都要反映。

MVU 输出（放在回复正文合适处，路径按 initvar 的结构）：

<UpdateVariable>
<Analysis>用一两句说明谁的哪项该变、为什么。</Analysis>
<JSONPatch>
[
  {"op":"replace","path":"/角色/林动/灵力","value":"70/120"},
  {"op":"replace","path":"/角色/林动/心境","value":"心神微乱"},
  {"op":"add","path":"/角色/林动/状态/-","value":"灵力透支"},
  {"op":"replace","path":"/角色/林动/灵石","value":1100}
]
</JSONPatch>
</UpdateVariable>
```
