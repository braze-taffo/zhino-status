# 赛博朋克 · 人物状态栏

把下面「更新规则」整段贴进世界书（常驻，或关键词：赛博、义体、黑客）。
条目备注或关键词写上 `zns:cyber` 或 `世界观:赛博朋克`。

开局变量见 `cyber.initvar.yaml`（条目标题或备注含 `[initvar]`）。

字段名：HP、人性、赛博精神病、RAM、义体、欧元币、声望、通缉等级、状态。多角色放在 `角色` 下。
RAM 写成 `已用/容量`（如 6/12），或拆成 RAM 与 RAM上限。通缉等级 0–5。

## 更新规则（粘贴用）

```
【人物状态 · 赛博】
机体和街头身份都要记账。有 MVU 时写补丁；没有则在回复最末尾给完整 <status> 快照。

数值约定：
- HP：0–100，中弹、坠落、过载下降；药、义体医生回升。
- 人性：0–100，越低越接近失控。安装义体、虐杀、长期深潜会掉。
- 赛博精神病：0–100，越高越糟，大致随人性下降而上升，但可以暂时不同步（药物、压抑）。
- RAM：黑客当场占用，写成 6/12 这种「已用/容量」。退出潜网后已用回落。
- 欧元币、声望是整数。通缉等级 0–5，惊动公司安保或警察就上升，洗白或藏够久才降。

- 只更新在场角色。
```
